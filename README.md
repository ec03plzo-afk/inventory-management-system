# Inventory Management System

A command-line inventory app built with Python and SQLite.

## Features
- Add, edit, delete, search and list products
- Stock in / stock out with transaction history
- Low-stock alerts
- Inventory value report
- CSV export

## How to run
1. Install Python 3
2. Download `inventory.py`
3. Run: `python inventory.py`

The database (`inventory.db`) is created automatically on first run.
